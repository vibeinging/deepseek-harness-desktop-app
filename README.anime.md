DeepSeek Harness Desktop App 是一个披着二次元外衣、认真把任务做完的本地 AI 工作桌面。看板娘负责陪你继续前进，DSH Session 负责保存消息、计划、工具、队列和运行轨迹。

![DeepSeek Harness Desktop App 二次元首页](docs/images/readme/dsh-work-home.png)

## 两套主题，两种工作状态

- `professional-blue` 是默认主题，适合日常项目工作与正式演示。
- `anime-blue` 是可选主题，启用后看板娘会出现在新对话首页。
- 两套主题都由 `@deepseek-ai/dsh-theme-pack` Profile Bundle 提供。
- 用户还可以新建、导入、预览、编辑、导出和删除自己的本地主题。

## 不只是换了一张皮肤

- 使用 DSH Agent、Tool、Skill、MCP、计划、待办和多 Agent。
- 管理项目、对话、记忆、文件授权和多个 Git Worktree。
- 查看 Diff、逐行编辑和 AI Review，并安全撤销模型产生的文件修改。
- 使用 Browser Workspace、文件搜索、Canvas、本地 Site 和 Office 产物。
- 在“结果与证据”中直接回放当前 DSH Session 的完整轨迹。

完整功能和平台说明见[正式 README](README.md#主要功能)。

## 开始使用

准备 Node.js 24 或更高版本：

```bash
npm install
npm run doctor
npm run dev
```
